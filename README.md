# Have You Tried Turning It Off?

One funny single-line reply from a hopeless tech support agent to a desperate customer, built for the make.fun bounty [u-motasimfuad-have-you-tried-turning-it-off-154a938b](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

The entry program (`main.ts`, Node 22, stdlib only) writes the line to `/output/entry.txt` and validates the gate: 1 to 199 characters, a single line, not only white space, plus a round-trip read-back check.

The line:

> Your ticket has been escalated to our senior team, which is me, in a different chair, with the same script.
